    Section 1.5 An Existence and Uniqueness Theorem

    Theorem 1.5.1.

    Given the initial value problem
    \begin{equation*} y'=f(t,y)\qquad y(t_0)=y_0 \end{equation*}
    • If \(f(t,y)\) is continuous in the open rectangle \(a\t t\lt b,c\lt y \lt d\) then the IVP has a solution in an open interval \(a\lt \alpha\lt t\lt \beta\lt b\) about the initial point \((t_0,y_0)\text{.}\)
      🔗
      🔗
    • If in addition the partial derivative \(f_y\) is also continuous the solution is unique.
      🔗
      🔗
    Notes
    • The theorem is a local existence theorem. It only guarantees a solution in a neighborhood of the initial point. It doesn’t give any information about the interval of existence.
      🔗
      🔗
    • The theorem gives sufficient conditions for an solution to exist. There can be solutions to an IVP even if the function \(f(t,y)\) isn’t continuous.
      \begin{equation*} y'=2\sqrt{y} \qquad y(0)=0 \end{equation*}
      has a solution \(y=t^2\) even though \(\sqrt{y}\) is not continuous at \((0,0)\)
      🔗
      🔗
    • The theorem is also true if there are more than one dependent variable and all the partial derivatives with respect to the dependent variables are continuous. For example, given the IVP
      \begin{equation*} x'=f(t,x,y)\quad y'=g(t,x,y)\qquad x(t_0)=x_0\quad y(t_0)=y_0 \end{equation*}
      then if \(f\) and \(g\) are continuous at \((t_0,x_0,y_0)\) then a solution exists. If the partial derivatives \(f_x,f_y,g_x,g_y\) are also continuous then the solution is unique.
      🔗
      🔗
    🔗
    🔗

    Example 1.5.2.

    Solve the differential equation
    \begin{equation*} y'=-3t^2(y-2)^2 \end{equation*}
    For the initial conditions
    \begin{equation*} (a) \quad y(0)=3 \qquad(b) \quad y(0)=1 \qquad(c) \quad y(0)=2 \end{equation*}
    🔗
    Firstly \(f=3t^2(y-2)^2\) and \(f_y=12t^2(y-2)\) are continuous everywhere so a unique solution exists for any initial condition.
    🔗
    Separating the variables and integrating
    \begin{equation*} \int \frac{dy}{(y-2)^2}=-\int 3t^2\,dt\quad\Rightarrow\quad \frac{1}{y-2}=t^3+c \end{equation*}
    \begin{equation*} y=2+\frac{1}{c+t^3} \end{equation*}
    (a)
    \begin{equation*} y(1)=3 =2+\frac{1}{c}\quad\Rightarrow\quad c=1\quad y(t)=2+\frac{1}{1+t^3} \end{equation*}
    (b)
    \begin{equation*} y(1)=1 =2+\frac{1}{c}\quad\Rightarrow\quad c=-1\quad y(t)=2+\frac{1}{t^3-1} \end{equation*}
    (c)
    \begin{equation*} y(2)=2 = 2+\frac{1}{c}\quad\Rightarrow\quad c=? \end{equation*}
    The problem goes back to separating the variables. If \(y(0)=2\text{,}\) dividing by \(y-2\) is not allowed. We know there is a unique solution from the theorem. Substituting \(y(t)=2\) into the differential equation shows that that is a solution. \(y(t)=2\) is an example of a singular or equilibrium solution
    🔗
    🔗

    Example 1.5.3.

    Consider IVPs associated with the differential equation
    \begin{equation*} y'=2t\sqrt{1-y^2} \end{equation*}
    Clearly if \(y_0^2\gt 1 \) the solutions will not exist. For \(|y|\lt 1\text{,}\) \(f=2t\sqrt{1-y^2}\) is continuous and \(y=\pm 1\) are singular solutions, so a solution will exist for \(-1\leq y_0\leq 1\text{.}\) For \(|y|\lt 1\) the partial derivative \(f_y=-2ty/\sqrt{1-y^2}\) is continuous, but \(f_y\) is undefined at \(y=\pm 1\text{.}\) So there is a possibility of non uniqueness at those \(y\) values.
    🔗
    Separating the variables and integrating
    \begin{equation*} \int\frac{dy}{\sqrt{1-y^2}}=\int 2t\,dt\quad\Rightarrow\quad \sin^{-1}y=t^2+c \end{equation*}
    Incorporating the initial condition gives
    \begin{equation*} y=\sin (t^2-t_0^2+\sin^{-1}y_0) \end{equation*}
    For \(y_0=1\) this becomes
    \begin{equation*} y=\sin\left(t^2-t_0^2+\frac{\pi}{2}\right) \end{equation*}
    But \(y=1\) is also a solution so there are at least two solutions hence non uniqueness.
    🔗
    The situation is actually worse. There are an infinite number of solutions. If \(y_0=1,t\lt 0\text{,}\) \(f=2t\sqrt{1-y^2}\) is negative so there is a choice between the singular solution and the sinusoidal solution. If \(y_0=-1\) the only possibility is the singular solution. For \(t\gt 0\) the situation is reversed, for \(y_0=1\) there is only the singular solution and for \(y_0=-1\) there is a choice.
