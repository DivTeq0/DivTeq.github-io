    Section 9.1 One independent variable

    The chain rule in single variable calculus can be expressed in the form
    \begin{equation*} y=f(g(x)) \quad\Rightarrow\quad \frac{dy}{dx}=\frac{df}{du}\,\frac{du}{dx}\quad \mbox{where} \quad u=g(x) \end{equation*}
    For derivatives of multivariable functions, the chain rule has a similar form. The difference is that their is a chain rule like term for each variable. For example
    \begin{equation*} u(t)=f(x(t),y(t),z(t))\quad\Rightarrow\quad \frac{du}{dt}=\frac{\partial f}{\partial x}\,\frac{dx}{dt}+\frac{\partial f}{\partial y}\,\frac{dy}{dt}+\frac{\partial f}{\partial z}\,\frac{dz}{dt} \end{equation*}
    🔗

    Example 9.1.1.

    Find \(\frac{du}{dt}\) given
    \begin{equation*} u=xy^2+e^{y+z}+\ln(z+2)+3x\qquad x=e^t\quad y=t-1 \quad z=\cos t \end{equation*}
    \begin{equation*} f_x=y^2+3 \qquad f_y=2xy+e^{y+z}\qquad f_z=e^{y+z}+\frac{1}{z+2} \end{equation*}
    \begin{align*} \frac{du}{dt} \amp = f_x x'+f_y y'+f_z z'\\ \amp = (y^2+3)(e^t)+(2xy+e^{y+z})(1)+\left(e^{y+z}+\frac{1}{z+2}\right)(-\sin t)\\ \amp =((t-1)^2+3)e^t+(2(t-1)e^t+e^{t-1+\cos t})+\left(e^{t-1+\cos t}\right)(-\sin t(\\ \amp +\left(\frac{1}{2+\cos t}\right)(-\sin t) \end{align*}
    🔗
    🔗

    Example 9.1.2.

    Suppose \(G(x,y)\) is a function that satifies
    \begin{equation*} G(3,-1)=2 \qquad G_x(3,-1)=-2\qquad G_y(3,-1)=3 \end{equation*}
    and define
    \begin{equation*} g(t)=G(t+3\cos 2t,-e^t) \end{equation*}
    Find the equation of the tangent to the curve \({\bf r}=\langle t,g(t)\) at \(t=0\text{.}\)
    \begin{equation*} g(0)=G(3,-1)=2 \end{equation*}
    \begin{align*} g'(t) \amp = G_x(t+3\cos 2t,-e^t)(1-6\sin 2t)+G_y(t+3\cos 2t,-e^t)(-e^t)\\ g'(0) \amp = G_x(3,-1)(1)+G_y(3,-1)(-1)=(-2)(1)+3(-1)=-5 \end{align*}
    So the equation of the tangent line is
    \begin{equation*} y-g(0)=g'(0)(x-0)\quad\Rightarrow\quad y=-5x+2 \end{equation*}

    A homogeneous function of order \(n\) satisfies the identity
    \begin{equation*} f(\lambda x,\lambda y,\lambda z)=\lambda^nf(x,y,z) \end{equation*}
    🔗

    Example 9.1.3.

    The function
    \begin{equation*} f(x,y,z)=\frac{y^4z+x^3y^2}{\sqrt{x^2+y^2+z^2}} \end{equation*}
    is a homogeous function of order 4 since
    \begin{equation*} f(\lambda x,\lambda y,\lambda z)=\frac{\lambda^5zy^4+\lambda^5x^3y^2}{\sqrt{\lambda^2x^2+\lambda^2y^2+\lambda^2z^2}}=\lambda^4\,\frac{y^4z+x^3y^2}{\sqrt{x^2+y^2+z^2}} \end{equation*}
    🔗
    🔗

    Theorem 9.1.4.

    (Euler) If \(f(x,y,z)\) is a homogeneous function of order \(n\) then it satisfies the equation
    \begin{equation*} x\frac{\partial f}{\partial x}+y\frac{\partial f}{\partial y}+z\frac{\partial f}{\partial z}=nf \end{equation*}
    🔗
    🔗
    Taking the derivative of the definition of a homogeneous function with respect to \(\lambda\)
    \begin{align*} n\lambda^{n-1}f \amp =\frac{d}{d\lambda}(f(\lambda x,\lambda y,\lambda z))\\ \amp = xf_x(\lambda x,\lambda y,\lambda z)+yf_y(\lambda x,\lambda y,\lambda z)+zf_z(\lambda x,\lambda y,\lambda z) \end{align*}
    Setting \(\lambda=1\) proves the theorem
