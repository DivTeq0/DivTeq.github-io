    Section 3.3 Electrical Circuits

    Electrical circuits are a fertile area for linear differential equations. For example consider the circuit
    🔗
    \begin{center} The voltages across the resistor and inductor are given in terms of the current \(i(t)\)
    \begin{equation*} V_R = Ri \qquad V_L=L\frac{di}{dt} \end{equation*}
    Kirchhoff’s law is that the voltages around the circuit add to zero which leads to the first order DE
    \begin{equation*} L\frac{di}{dt}+Ri=V(t) \end{equation*}
    This is a linear equation with integrating factor
    \begin{equation*} \mu(t) = e^{Rt/L} \end{equation*}
    So the current is
    \begin{equation*} i(t)=e^{-Rt/L}\int\frac{V(t)}{L}e^{Rt/L}\,dt \end{equation*}
    🔗

    Example 3.3.1.

    If \(V (t) = V_0\) a constant and \(i(0)=o\) then
    \begin{equation*} i(t)=e^{-Rt/L}\int\frac{V_0}{L}e^{Rt/L}\,dt=e^{-Rt/L}\left(\int\frac{V_0}{R}e^{Rt/L}+c_1\right) \end{equation*}
    using the initial condition \(i(0) = 0\) gives \(c_1=-V_0/R\) and the solution is
    \begin{equation*} i(t) =\frac{V_0}{R}(1 - e^{-Rt/L} ) \end{equation*}
    The current starts from 0 and asymptotes to the steady state value \(V_0 /R\)
    🔗
    🔗

    Example 3.3.2.

    If \(V(t)=V_0\cos(\omega t)\) and \(i(0)=0\text{.}\) The solution is
    \begin{equation*} i(t)=\frac{V_0}{L} e^{-Rt/L}\int\cos(\omega t)e^{Rt/L}\,dt \end{equation*}
    Using the integral from the second example in the first section gives the general solution
    \begin{equation*} i(t)=\frac{V_0}{R^2+\omega^2L^2}(R\cos\omega t+\omega L\sin \omega t)+ce^{-Rt/L} \end{equation*}
    Using the initial condition \(i(0) = 0\) gives the solution
    \begin{equation*} i(t)=\frac{V_0}{R^2+\omega^2L^2}(R(\cos\omega t-e^{-Rt/L}+\omega L\sin \omega t) \end{equation*}
