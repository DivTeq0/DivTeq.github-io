    Section 11.1 Critical points

    A quick review of some facts about local extrema (minima and maxima) in single variable calculus
    • A function, \(f\text{,}\) has a local minimum at \(x_0\) if there is an open interval, \(I\text{,}\) containing \(x_0\) with \(f(x)\geq f(x_0)\) for all \(x\in I\text{.}\) It has a local maximum if \(f(x)\leq f(x_0)\) for all \(x\in I\)
      🔗
      🔗
    • A point \(x_0\) is a critical point of \(f\) if either \(f'(x_0)=0\) or \(f'(x_0)\) doesn’t exist \item If \(f'(x_0)\) exists then if \(f\) has a local minimum or maximum then \(f'(x_0)=0\text{.}\) The converse isn’t true, for example if \(f(x)=x^3\text{,}\) \(f'(0)=0\) but \(f\) has neither a maximum or minimum at \(0\text{.}\)
      🔗
      🔗
    • If \(f''(x_0)\neq 0\) exists then the Taylor series for \(f\) near the critical point has the form
      \begin{equation*} f(x)=f(x_0)+\frac{f''(x_0)}{2}(x-x_0)^2 + \cdots \end{equation*}
      Then for points close to the critical point if \(f''>0\,\Rightarrow\,f(x)>f(x_0)\) and the point is a local minimum or if \(f''<0\,\Rightarrow\,f(x)<f(x_0)\) and the point is local maximum.
      🔗
      🔗
    • If \(f''(x_0)=0\) the higher order terms have to be examined to classify the point.
      🔗
      🔗
    🔗

    Subsection 11.1.1 Critical points for functions of two variables

    A point \((x_0,y_0)\) is a critical point for a function \(f(x,y)\) if \(\boldsymbol{\nabla} f(x_0,y_0)\) doesn’t exist or if \(f(x,y)\) satisfies
    \begin{equation*} \boldsymbol{\nabla} f(x_0,y_0)=0 \qquad \mbox{or} \qquad f_x(x_0,y_0)=f_y(x_0,y_0) = 0 \end{equation*}
    Geometrically this means that the tangent plane to the graph of \(z=f(x,y)\) is horizontal (or vertical) at \((x_0,y_0)\text{.}\)
    🔗
    A function of two variables \(f(x,y)\) has a local maximum at \((x_0,y_0)\) if \(f(x,y) \leq f(x_0,y_0)\) for all points in a disk with center \((x_0,y_0)\text{.}\) It has a local minimum at \((x_0,y_0)\) if \(f(x,y) \geq f(x_0,y_0)\) for all points in a disk with center \((x_0,y_0)\text{.}\)\ As in single variable calculus, the local extrema (maxima and minima) are critical points but not all critical points are extrema.
    🔗
    🔗

    Example 11.1.1.

    Find the critical points of the function
    \begin{equation*} f(x,y)=x^2+y^2-2x-6y+16 \end{equation*}
    🔗
    \begin{equation*} f_x=2x-2=0 \quad f_y=2x-6=0 \quad\Rightarrow x=1\quad y=3 \end{equation*}
    The function has only one critical point and it is a minimum since \(f\) can be written in the form
    \begin{equation*} f(x,y)=(x-1)^2+(y-3)^2+4 \end{equation*}
    🔗
    🔗
    🔗

    Subsection 11.1.2 Taylor series near a critical point

    Suppose that \(f(x,y)\) has a critical point at \((x_0,y_0)\text{.}\) Then \(f_x(x_0,y_0))=f_y(x_0,y_0)=0\text{.}\) The Taylor series near the critical point will have the form
    \begin{equation*} f(x,y)=f(x_0,y_0)+\frac{1}{2}\left(f_{xx}(\Delta x)^2+2f_{xy}\Delta x \Delta y + f_{yy}(\Delta y)^2 \right) + \mbox{higher order terms} \end{equation*}
    where
    \begin{equation*} \Delta x=x-x_0 \qquad \Delta y=y-y_0 \end{equation*}
    and the second derivatives are evaluated at \((x_0,y_0)\text{.}\) If we are close enough to \((x_0,y_0)\) i.e. \(\Delta x, \Delta y\) are small enough so the higher order terms can be neglected, then the nature of the critical point is governed by the behavior of the quadratic terms. If the quadratic term, \(Q\) is positive, the critical point is a minimum.
    If it is negative it is a maximum.
    If it has no definite sign it is a saddle.
    The saddle is a new type of critical point. Geometrically in one direction it has a minimimum and in another a maximum.
    🔗
    🔗

    Subsection 11.1.3 Second derivative test

    By completing the square the quadratic term can be written in the form
    \begin{equation*} Q =f_{xx}(\Delta x)^2 +2f_{xy}\Delta x\Delta y+f_{yy}(\Delta y)^2=f_{xx}\left(\Delta x+\frac{f_{xy}}{f_{xx}}\Delta y\right)^2+\frac{f_{xx}f_{yy}-f_{xy}^2}{f_{xx}}(\Delta y)^2 \end{equation*}
    Let \(D=f_{xx}f_{yy}-f_{xy}^2\text{,}\) then the second derivative test is
    • If \(D(x_0,y_0) \gt 0\) and \(f_{xx}(x_0,y_0) \lt 0\) then \(Q \lt 0\) and \((x_0,y_0)\) is a local maximum
      🔗
      🔗
    • If \(D(x_0,y_0) \gt 0\) and \(f_{xx}(x_0,y_0) \gt 0\) then \(Q \gt 0\) and \((x_0,y_0)\) is a local minimum
      🔗
      🔗
    • If \(D(x_0,y_0) \gt 0\) then \(Q\) has an indefinite sign and \((x_0,y_0)\) is a saddle
      🔗
      🔗
    • If \(D(x_0,y_0) = 0\) the test is inconclusive
      🔗
      🔗
    🔗
    🔗

    Example 11.1.2.

    Find and classify the critical points of the function
    \begin{equation*} f(x,y)=x^3-6xy+y^2 \end{equation*}
    \begin{equation*} f_x=3x^2-6y=0 \quad f_y=-6x+6y=0\quad\Rightarrow x=0,y=0 \qquad x=2,y=2 \end{equation*}
    \begin{equation*} f_{xx}=6x \quad f_{yy}=6 \quad f_{xy}=-6 \quad\Rightarrow \quad D=36x-36 \end{equation*}
    \(D(0,0)=-36\) so \((0,0)\) is a saddle. \(D(2,2)=36, f_{[x}=12\gt 0\) so \((2,2)\) is a minimum
    🔗
    🔗

    Subsection 11.1.4 Extrema on Bounded Domains

    As in single variable calculus, continuous functions on closed domains achieve both their maximum and minimum values. In the two variable case if the maximum (or minimum) don’t occur in the interior of the region they must occur on the boundary
    🔗

    Example 11.1.3.

    Find the maximum and minimum values of the function \(f(x,y)=x^2-2xy+2y\) on the rectangle \(0\leq x \leq 3, 0\leq y \leq 2\)
    🔗
    The critical points are given by
    \begin{equation*} f_x=2x-2y=0 \quad f_y=-2x+2=0 \quad \Rightarrow x=1,y=1 \end{equation*}
    \begin{equation*} f_{xx}=2 \quad f_{yy}=0 \quad f_{xy}=-2 \quad \Rightarrow\quad D=-4 \end{equation*}
    so \((1,1)\) is a saddle and the maximum and minimum must lie on the boundary.
    🔗
    On \(C_1\)
    \begin{equation*} f(x,0)=x^2 \quad 0\leq x\leq 3 \qquad \mbox{Max:}\,f(3,0)=9\quad \mbox{Min:}\,f(0,0)=0 \end{equation*}
    On \(C_2\)
    \begin{equation*} f(3,y)=9-4y \quad 0\leq y\leq 2 \qquad \mbox{Max:}\,f(3,0)=9\quad \mbox{Min:}\,f(3,2)=1 \end{equation*}
    On \(C_3\)
    \begin{equation*} f(x,2)=x^2-4x+4 \quad 0\leq x\leq 3 \quad \mbox{Max:}\,f(0,2)=4\quad \mbox{Min:}\,f(2,2)=0 \end{equation*}
    On \(C_4\)
    \begin{equation*} f(0,y)=2y \quad 0\leq y\leq 2 \qquad \mbox{Max:}\,f(0,2)=4\quad \mbox{Min:}\,f(0,0)=0 \end{equation*}
    So the absolute maximum is \(9=f(3,0)\) and the absolute minimum is \(0=f(0,0)=f(2,2)\text{.}\)
